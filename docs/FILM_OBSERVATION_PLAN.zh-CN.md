# dngscan 胶片观察位置：设计与实现合同

> 文档用途：记录"胶片观察位置"功能群的设计决定、数据出处策略、生产合同与验收边界。
>
> 状态：设计已定，待实施。第零层（固定色温白平衡）已于 5d1b889 落地。
>
> 定位一句话：**一个带有"可标定的胶片观察位置"的 tone mapping 工具，不是胶片模拟器。**

## 0. 结论先行

胶片"看"世界的方式可以分解为四个独立的、各有公开出处的层，每层在 dngscan 管线里
都有唯一正确的位置：

```
解码            [镜前滤镜]         [光谱前馈]          AgX formation        交付
WB=声明观察位置   改变入射光         更换观察者           显影曲线坐标          SDR/HDR
固定色温(已完成)  Wratten 透过率     胶片光谱感度         特性曲线拟合预设      不变
```

三个准入条件（继承自 WB 固定色温的先例）：

1. **有公开标准或数据手册作为出处**——不接受"调到好看为止"；
2. **在管线四层里有明确的层位**——不接受跨层烘焙（这正是 LUT 的病）；
3. **拟合质量可测量、可报告**——每个预设携带 `source` 与 `fit_residual`，
   如同 WB 的"0.1% 吻合"和前馈的 `confidence`。

明确的非目标（划出"胶片模拟器"的边界）：

- 不做颗粒、halation、相纸纹理、扫描仿真、片基色罩视觉化；
- 不做逐像素光谱上采样（从 RGB 猜光谱是不适定的；我们在 RAW 端工作，
  相机的光谱积分是真实发生过的）；
- 不替换 AgX formation——AgX 的 C1 曲线族、path-to-white 与全部既有合同原样保留，
  胶片曲线是这个参数空间里的**具名坐标点**，不是另一条管线；
- 不牺牲 HDR——胶片性格必须能进 Ultra HDR 交付，这是本功能群与市面所有
  胶片工具（含 spektrafilm）的根本差异点。

## 1. 与 spektrafilm（agx-emulsion）的关系

它做正向全链模拟（RGB→猜光谱→胶片感度→耦合剂→颗粒→相纸→扫描），锁定 print-referred
SDR；我们做分解式标定（RAW→声明观察位置→分材料色彩分离→参数化显影曲线），保持
scene-referred 直到 formation，因此 HDR 可达。两者在"数据手册的机器可读化"上握手：

- 它整理的胶片光谱感度、染料密度、特性曲线数据（GPL 生态，与本仓库许可兼容）
  作为首选数据源，逐文件在 `dngscan_assets/spectral/` 的 README 与 NOTICE.md 中
  记录出处与许可；
- 它的相机端空白（输入 RGB 被假设为真值，相机光谱指纹未建模）正是我们前馈层的
  存在理由；两个项目互补，不竞争。

## 2. 第一层：镜前滤镜（Wratten 转换滤镜）

### 2.1 物理与层位

滤镜是镜头前的玻璃：`I'(λ) = T(λ)·I(λ)`，作用于光、先于感光。数字模拟位置：
解码（含 WB）之后、前馈之前的 scene-linear Rec.2020。经传感器积分后，
光谱滤镜到一阶是一个**全局 3×3**（近对角）矩阵；与逐通道 WB 增益的差集中在
饱和材料与窄谱光源——那个残差就是"滤镜感"。

### 2.2 为什么不是 scene_transform 预设

现有前馈合同明文"中性轴不变"；而转换滤镜的**目的就是移动中性轴**
（3200K 卷 + 85B ≈ 日光中性，组合近似闭合但不精确——残差是历史工作流的指纹）。
为不破坏前馈合同，滤镜作为独立小阶段实现：

- 新模块 `dngscan/lens_filter.py`：全局矩阵一次乘法，`strength` 无——滤镜没有
  半片玻璃，只有装或不装；
- 预设 JSON `dngscan/lens_filter_presets.json`：`name / matrix / source /
  fit_residual / cct_shift_expected / exposure_factor`；
- CLI `--lens-filter {none,85,85b,80a,81a,82a}`；GUI 放在"RAW 解码"卡
  （它是采集光学，不是颜色创作）。

### 2.3 推导与验收

离线工具 `tools/derive_lens_filter.py`：对 AMPAS 190 训练反射谱 × 目标光源 ×
参考观察者，分别积分"有滤镜/无滤镜"两组三刺激值，在 Rec.2020 线性域最小二乘拟合
3×3。数据源：柯达出版的 Wratten 透过率曲线（数字化 CSV 入库，标注出版物版本）。

验收门（`tests/test_lens_filter.py`）：

```text
CCT 位移：合成 D55 过 85B 后 CCT ∈ 3200K ± 150K（各滤镜按 mired 表逐一给出）
曝光因子：矩阵行和的 -log2 与出版滤镜因子偏差 ≤ 1/6 EV
拟合残差：190 反射谱上 RMS ΔRGB ≤ 声明阈值，写入预设
组合闭合：3200K WB + 85B 对中性样本的残余偏移有界且被记录（这是特征，不是 bug）
HDR/SDR：一次齐次性（曝光乘 2 输出乘 2）精确成立
```

## 3. 第二层：光谱前馈转正（胶片作为观察者）

### 3.1 设计不变

机制零改动：分材料色度窗口 + 约束 3×3 + 中性轴保持 + von Kries 窗口搬运 +
置信度缩放——全部沿用。改变的只有**拟合目标**：把"数字化 ALEV 猜测"换成
"数据手册印着的胶片光谱感度"。在现有标定器的框架里，**胶片就是另一台相机**：
`calibrate_skin_matrix.py` 已支持双机拟合，替换目标侧 SSF 的 CSV 即可复用全部
基础设施（190 反射谱 profile、分类别拟合、泄漏矩阵、置信度报告）。

### 3.2 语义澄清（写进 docstring 的合同）

前馈胶片预设映射的是**色彩分离差异**（"Portra 的光谱感度会把这些材料的颜色
分离成什么关系"），不是密度/色调（那属于 formation 层）。胶片三层曝光量被当作
三刺激空间，经与相机侧完全相同的 190 反射谱流程 profile 到 Rec.2020——两侧
对称，误差同源可比。

### 3.3 交付物与验收

- 数据：**双旗舰首发——Kodak Portra 400 与 Fujifilm Superia X-TRA 400**
  （西方与东方各自最深入记忆的一卷）。相机侧维持 A7III + 热镜模型代理，
  `confidence` 机制如实降权（换真实测量时预设自动受益，机制不变）；
- Superia 专项注记：
  1. **第四感色层**——Superia 的青敏第四层是它在混合光下色彩记忆的一部分。
     若 datasheet 暴露第四层感度曲线，前馈把胶片当作**四通道观察者**处理
     （profile 拟合从 3×3 扩为 3×4，标定器小改）；若仅并入三层曲线，
     按三层近似并在预设 note 里如实标注；
  2. **数据自洽性**——spektrafilm 作者的实测经验：富士 datasheet 数据自洽性
     低于柯达。预期 Superia 预设的 confidence 系统性低于 Portra，这是数据
     现实的诚实反映，不做人为拉平；
  3. **版本钉定**——Superia X-TRA 400 历经 1998/2003/2006 三版并于 2024 停产
     （继任"Fujifilm 400"为美产乳剂，非同一款）。预设 `source` 必须写明
     所据 datasheet 的版本与年份；
- 预设：`portra400_d55` 与 `superia400_d55`（材质窗口沿用
  skin/foliage/cyan/neutral/magenta，按需增 sky 类——Superia 的
  第四层对荧光/混合光场景的意义可能要求增补 fluorescent 窗口，实测定），
  每类携带 `source / confidence / fit_residual`；
- 测试：现有前馈套件全部沿用（中性轴、置信度缩放、WB 搬运、分量窗口），
  新增：各类拟合残差入预设并断言 ≤ 阈值；泄漏矩阵越界告警；
- A/B：`tools/hdr_ab.py` 风格的对比页，回归样张 × {关/开} 前馈，
  存 `docs/assets/`。

## 4. 第三层：formation 曲线预设（AgX 参数空间里的具名坐标）

### 4.1 设计决定

AgX 不被替换——它就是胶片曲线族（卤化银词源、H&D 型 toe/shoulder、逐通道
path-to-white 对应染料耦合剂耗尽）。"Portra 预设"= 在 AgX 参数空间
（contrast / toe_power / shoulder_power / latitude_lo/hi / black_ev / white_ev）里
由数据手册特性曲线**最小二乘解出的一个点**，携带出处与残差。

关键决定：**胶片预设锁定整条曲线参数（含端点），场景自适应关闭。**
理由：胶片响应是固定的——同一场景永远得到同一密度，"整卷一致"正是用户
选择它的原因（与 WB 固定色温同一逻辑）。黑白端点由数据手册直线段宽容度给出，
不再随场景漂移。EV0 → 0.18 的 pivot 锚定合同**必须保持**：拟合时先解曝光偏置
把胶片的中灰放置对齐到 0.18，再拟合形状。

### 4.2 HDR 组合（旗舰场景）

胶片预设 + HDR：预设曲线是 K 以下的 body，可靠尾部照常挣取 K 以上的
log-stop shoulder——"Portra 的身体 + 诚实的 HDR 高光"，市面无第二家。
预设的 contrast 值必须进 α 域扫描（细分机制已就位，扫描只为刻画禁用区不存在）。

### 4.3 交付物与验收

- 离线工具 `tools/fit_film_curve.py`：输入数字化特性曲线（负片 + 端到端
  正像），输出 AgX 参数 + 残差报告 + 目标/拟合曲线对照图；
- 数据：Portra 400 与 Superia X-TRA 400 特性曲线 CSV（datasheet 数字化，
  标注版本；两款并行走同一工具，残差各自报告）；
- 管线：`ToneCompressionPlan` 增加 `curve_preset` 具名来源；
  `build_render_plan` 在预设激活时跳过场景自适应压缩编译（复用
  用户 adjustments 的 override 通道，明暗微调仍可叠加——微调作用于
  预设坐标附近，且如实报告）；
- 测试门：

```text
拟合残差：RMS ≤ 0.08 stop（-6..+3 EV），最大 ≤ 0.15 stop，写入预设；
        每个预设的存储残差与复算值互差 ≤ 0.005 stop（回归钉定，
        天花板之下不允许漂移藏身）
  （标定注：合同初版的 0.05 是数据到来前的猜测。实测 AgX toe 族与
   Portra/Endura 相纸膝部的结构性距离为 RMS 0.058——放宽参数边界只能
   改善 0.001，证明这是曲线族距离而非优化不足。门限按实测加余量重标，
   与 delivery 门限重标定同一先例；Superia 实测 0.021，远在门内。）
EV0 = 0.18，误差 ≤ 1e-5（沿用既有合同）
C1 编译有效：compile 不失败、单调、端点契约全过
α 扫描：预设 contrast × 全 headroom 轴 × tail 域，权威曲线全部可编译
SDR 冻结：预设关闭时逐字节不变
HDR：预设开启时 formation/delivery 全套测试通过
```

## 5. 组合语义与 UI

"Portra 400"作为一个**组合预设**呈现（GUI 一个下拉、CLI 一个
`--film portra400`），展开为三个独立声明：WB 5500k + 前馈 portra400_d55 +
曲线 portra400。三层各自可单独开关（高级用户），组合预设只是捆绑——
**没有任何一层在另一层里烘焙**。描述行如实报告：
`胶片观察：Portra 400（WB 5500K · 分离 conf 0.7 · 曲线残差 0.03 stop）`。
投递报告面板增列当前观察位置。

## 6. 实施顺序与提交边界

按价值与依赖排序，每步全套测试后提交：

1. `docs:` 本合同入库；
2. `data:` 胶片光谱/曲线数据导入 + 出处与许可记录（NOTICE.md、spectral/README）；
3. `tools+tone:` fit_film_curve + 曲线预设管线 + α 扫描 + 测试
   （最大可见价值，先行）；
4. `prefeed:` 胶片 SSF 拟合目标 + portra400_d55 预设 + 测试 + A/B 页；
5. `capture:` lens_filter 阶段 + Wratten 推导 + 测试；
6. `ui:` 组合预设（GUI/CLI）+ 描述行 + 投递报告列 + 使用说明/README 双语更新
   + 对比图。

粗估：3≈1 天，4≈1 天（数据工程为主），5≈半天，2/6≈各半天。
每阶段独立可交付，中途停下不留半成品层。

## 7. 风险与开放决定

- **数据许可**：spektrafilm 数据复用前逐文件核对许可与出处链（任务 2 的门槛）；
  Wratten 曲线若无现成机读数据则自行数字化并公开 CSV；
- **相机侧代理**：fp 真实 SSF 仍未测量，前馈精度上限由 confidence 如实呈现——
  这是已知边界，不阻塞（同 REVIEW_FINDINGS 时代的结论）；
- **明暗微调与固定曲线的关系**：默认允许叠加并在描述行报告"偏离预设"；
  若实测发现语义混乱，收紧为预设激活时锁定微调（开放决定，实测后拍板）；
- **首发胶片**：Portra 400 + Superia X-TRA 400 双旗舰（东西方记忆之卷；
  Portra 数据最全做基准，Superia 检验富士数据链并首验四通道观察者路径）；
  第二批 Ektar 100 / Vision3 250D / 一款黑白（黑白只需曲线层 +
  全局去饱和语义，另议）。
